PL-004 RESOLVED: This document absorbs and retires
the old 0511005 Safety_Parameter_Review_Procedure.
That procedure governed the Binance-era TothBot and
required mandatory human review before any parameter
change. In TothBot V2, CIATS owns all parameter values

is required only for the initial deployment of each
CIATS proposal. Old 0511005 is archived in _Archive
as read-only reference. It does not apply to V2.

============================================================
1. PURPOSE
============================================================

This document is the complete, authoritative registry of
all Risk-domain parameters in TothBot V2. It defines every
risk parameter: its starting value, CIATS ownership status,
activation condition, change constraints, governing
specification reference, and FP/DP validation source.

It also defines the sole hardcoded exception — net 1:1.5
R:R — and establishes the framework rules that govern how
CIATS may and may not change any parameter in this domain.

A coder reading this document must be able to initialize
the Parameter Store with all Risk-domain starting values
and implement all CIATS parameter update constraints
without asking any questions.

4. THE HARDCODED EXCEPTION — NET 1:1.5 R:R
============================================================

  SPF-HC-001  Net 1:1.5 R:R is the ONLY hardcoded
              constraint in TothBot V2.

              CIATS does not own this value.
              Bill does not change this value.
              No PDCA cycle governs this value.
              No data can change this value.
              It is permanent. It is enforced in code.
              It never changes. No exception. No override.

  SPF-HC-002  Definition:
                net_gain = net_loss * Decimal("1.5")
              Where net_loss includes all entry and exit
              fees on the loss side. This ensures that
              every trade targets at minimum 1.5 units
              of realized net gain for every 1 unit of
              realized net risk after all fees.

  SPF-HC-003  Enforcement point: Gate 8 Position Sizer
              (0611001). Encoded directly in the R:R
              formula. No runtime parameter lookup.
              The multiplier 1.5 is a code literal,
              not a Parameter Store value.

  SPF-HC-004  RATIONALE: The 1:1.5 R:R constraint is the
              system's primary loss-prevention mechanism
              at the trade level. It ensures that even
              at a 40% win rate, the strategy is
              profitable. Allowing CIATS to optimize this
              value introduces the risk that data noise
              during early trading produces a sub-1:1
              R:R proposal, permanently degrading the
              system's loss floor. No data justifies
              that risk. It is hardcoded.

5. PARAMETER OWNERSHIP FRAMEWORK
============================================================

  SPF-OWN-001  All Risk-domain parameters except net
               1:1.5 R:R are CIATS-owned starting values.
               "CIATS-owned" means:
                 - CIATS may propose changes after the
                   200-trade statistical floor is reached.
                 - Bill approves the initial deployment
                   of each CIATS proposal.
                 - No mandatory human review is required
                   for subsequent CIATS updates.
                 - No parameter has a ceiling or floor
                   (except constraints imposed by other
                   architectural rules).
                 - Parameters are not sacred. They are
                   starting points subject to replacement
                   by data.

  SPF-OWN-002  Starting values are derived from FP/DP
               analysis using appropriate statistical
               methodologies (5+ independent sources per
               parameter, TB00000 Section 5.3). They are
               the best available values before real
               market data is available. They are not
               guesses.

  SPF-OWN-003  CIATS parameter changes must maximize
               profit and minimize loss, with an emphasis
               on minimizing loss. No parameter change
               is valid if it increases loss exposure
               without a statistically significant
               improvement in returns.

  SPF-OWN-004  The 200-trade floor is absolute. CIATS
               does not propose parameter changes below
               200 closed trades regardless of what the
               data appears to show. Below 200 trades,
               CIATS monitors only (EWMA Monitor via
               Stream 1). The Proposal Engine is inactive
               below 200 trades.

  SPF-OWN-005  Minimum 50-trade interval between any two
               CIATS parameter changes after the 200-trade
               floor. Prevents over-optimization and
               ensures statistical independence between
               change events (CIATS-PDCA-001 in 1011010).

6. RISK-DOMAIN PARAMETER REGISTRY
============================================================

Format per entry:
  Parameter:    name

------------------------------------------------------------
6.1 Capital Allocation Parameters
------------------------------------------------------------

  Parameter:    tradeable_pct
  Value:        Decimal("0.50")  (50% of portfolio_USD)
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  Fraction of realized cash portfolio
                committed to active trading. The
                remaining 50% is held in reserve.
  Spec:         0611001 PS-TRADE-001, PS-TRADE-002
  Validation:   AR-051. 50% reserve provides capital
                buffer against simultaneous adverse
                positions across all concurrent slots.
                FP/DP validated starting point.

  Parameter:    per_trade_pct
  Value:        Decimal("0.05")  (5% of tradeable_USD)
  Type:         CIATS-OWNED (Phase 1 only)
  Activation:   Replaced by Half-Kelly at 200 closed
                trades. CIATS manages Kelly inputs (W
                and R) thereafter. per_trade_pct becomes
                inactive at 200-trade activation.
  Description:  Fraction of tradeable_USD allocated
                to each individual trade in Phase 1.
  Spec:         0611001 PS-PTA-001, PS-HK-001 through
                PS-HK-007
  Validation:   AR-051. 5% per trade with 20 max
                concurrent = 100% tradeable deployment
                at maximum capacity. Conservative for
                paper trading start. FP/DP validated.

  Parameter:    max_concurrent
  Value:        20  (integer, not Decimal)
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  Maximum number of simultaneously open
                positions. Enforced by BoundedSemaphore.
  Spec:         0611003 CE-MC-001, CE-SEM-001 through
                CE-SEM-011
  Validation:   AR-043. 20 positions provides adequate
                diversification across the monitored
                universe while keeping per-position
                exposure manageable. FP/DP validated.

------------------------------------------------------------
6.2 Exit Distance Parameters
------------------------------------------------------------

  Parameter:    mae_mult
  Value:        Decimal("1.5")  (multiplier on ATR(14))
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  ATR multiplier for the MAE (Maximum
                Adverse Excursion) threshold. Defines
                the Layer 2 exit trigger distance from
                entry fill price.
                mae_price = entry_fill_price *
                    (1 - ATR(14) * mae_mult
                         / entry_fill_price)
  Spec:         0611001 PS-RR-001, PS-RR-002
  Validation:   AR-011. ATR-dynamic stops validated:
                +15% performance, -22% max drawdown vs
                fixed stops (LuxAlgo + 4 sources, 5+
                independent sources, 0500000 Finding 2).
                1.5x ATR is the loss side of the sacred
                1:1.5 R:R. CIATS may adjust this value
                but cannot violate net 1:1.5 R:R.

  Parameter:    emergency_sl_mult
  Value:        Decimal("3.0")  (multiplier on ATR(14))
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  ATR multiplier for the off-book emergency
                stop-market price (Layer 3). Crash
                protection only — fires ONLY on
                VPS/TothBot/internet failure. Must never
                fire in normal operation.
                emergSL_price = entry_fill_price *
                    (1 - ATR(14) * emergency_sl_mult
                         / entry_fill_price)
                NOTE: emergSL_dist is NEVER part of the
                R:R formula. It is computed separately
                for order placement only.
  Spec:         0611001 PS-RR-006, PS-RR-007, PS-RR-008
  Validation:   AR-011. 3.0x ATR provides sufficient
                clearance from normal price action to
                ensure the emergency SL does not fire
                on volatility while still providing
                meaningful crash protection. FP/DP
                validated. 2x mae_mult by design.

------------------------------------------------------------
6.3 Entry Timing Parameters
------------------------------------------------------------

  Parameter:    entry_timeout_sec
  Value:        30–60 seconds  (CIATS-owned range)
  Type:         CIATS-OWNED
  Activation:   Day 1 of paper trading (CIATS may
                adjust within range from start)
  Description:  GTD (Good Til Date) window for entry
                limit orders. Post_only guarantee means
                the entry either fills as a maker or
                expires without fill. The timeout
                prevents stale orders from filling at
                an unintended price after conditions
                change.
  Spec:         0511003 (Execution Engine), 0411001
                WS-GTD-001 (order format)
  Validation:   AR-006. 30-60s balances fill probability
                on the 5-minute candle close event
                against the risk of holding an active
                order through a rapid adverse move.
                Starting range — CIATS optimizes the
                specific value within and potentially
                beyond this range after data is available.

------------------------------------------------------------
6.4 Circuit Breaker Parameters
------------------------------------------------------------

  Parameter:    session_pause_drawdown
  Value:        Decimal("0.05")  (5% of portfolio baseline)
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  Drawdown threshold at which TothBot
                pauses new entries. Existing positions
                monitored and exited normally.
                Auto-resumes when drawdown recovers.
  Spec:         0611002 DD-SP-001 through DD-SP-005
  Validation:   AR-052. TB00016 C-11 confirmed 5%
                appropriate. Conservative enough to
                signal a meaningful adverse run without
                triggering on normal intraday volatility.
                FP/DP validated.

  Parameter:    full_halt_drawdown
  Value:        Decimal("0.10")  (10% of portfolio baseline)
  Type:         CIATS-OWNED
  Activation:   200 closed trades
  Description:  Drawdown threshold at which TothBot
                fully halts. All open entry orders
                canceled via batch_cancel. Existing
                positions monitored and exited normally.
                Manual operator restart required to
                resume.
  Spec:         0611002 DD-FH-001 through DD-FH-006
  Validation:   AR-052. TB00016 C-11 confirmed 10%
                appropriate. 2x the session pause
                threshold — provides a meaningful
                escalation step before a full halt.
                FP/DP validated.

7. PARAMETER STORE INITIALIZATION
============================================================

  SPF-INIT-001  At TothBot startup, the Parameter Store
                is initialized with all starting values
                defined in Section 6. No parameter is
                uninitialized at startup.

  SPF-INIT-002  Parameter Store initialization order
                (all Risk-domain parameters):
                  tradeable_pct         = Decimal("0.50")
                  per_trade_pct         = Decimal("0.05")
                  max_concurrent        = 20
                  mae_mult              = Decimal("1.5")
                  emergency_sl_mult     = Decimal("3.0")
                  entry_timeout_sec     = 45
                  session_pause_drawdown = Decimal("0.05")
                  full_halt_drawdown    = Decimal("0.10")
                  half_kelly_active     = False
                  half_kelly_W          = None
                  half_kelly_R          = None

                NOTE: entry_timeout_sec initialized to 45
                (midpoint of 30-60s range). CIATS adjusts
                from first paper trade.

                NOTE: half_kelly_active initialized False.
                CIATS sets True at 200 closed trades.
                half_kelly_W and half_kelly_R initialized
                None — populated by CIATS at activation.

  SPF-INIT-003  The Parameter Store snapshot pattern
                (I-4) applies to all parameters above.
                TothBot takes a frozen snapshot at the
                start of each pipeline evaluation. CIATS
                writes to the live Parameter Store only
                at inter-trade boundaries. The snapshot
                and the live store are never in conflict
                within a single pipeline evaluation.

  SPF-INIT-004  net_1_5_RR is NOT in the Parameter Store.
                It is a code literal. It cannot be read,
                written, or modified through any Parameter
                Store operation.

8. CIATS CHANGE CONSTRAINTS — RISK PARAMETERS
============================================================

  SPF-CHG-001  No Risk-domain parameter may be changed
               by CIATS below 200 closed trades.
               Below 200 trades: starting values are
               in effect and immutable from CIATS.
               Above 200 trades: CIATS Proposal Engine
               is active and may propose changes.

  SPF-CHG-002  Minimum 50-trade interval between any
               two parameter changes. If CIATS proposes
               a change to tradeable_pct, the next
               parameter change of any kind cannot occur
               until 50 more trades have closed.

  SPF-CHG-003  Every CIATS parameter change must be
               supported by Mann-Whitney U with p < 0.01
               (one-sided). 99% confidence required for
               all Risk-domain parameter changes.
               Rationale: financial risk parameters
               require higher confidence than general
               signal parameters. 0.05 produces too
               many false-positive changes.

  SPF-CHG-004  Every proposed change must demonstrate
               improvement in the loss-minimization
               direction. A change that improves returns
               at the cost of increased drawdown risk
               requires explicit justification and a
               higher confidence threshold.

  SPF-CHG-005  mae_mult changes are constrained by the
               sacred 1:1.5 R:R. CIATS may not propose
               a mae_mult value that, combined with the
               current fee structure, would cause net R:R
               to fall below 1:1.5 for any valid trade.
               The R:R formula enforces this at Gate 8,
               but CIATS must not propose a violating
               value regardless.

  SPF-CHG-006  max_concurrent changes require semaphore
               recreation per 0611003 CE-SEM-009 through
               CE-SEM-011. CIATS writes the new value.
               The implementation handles recreation.
               CIATS does not need to know the semaphore
               implementation — it writes the value only.

  SPF-CHG-007  entry_timeout_sec changes take effect on
               the next entry dispatch after the Parameter
               Store write is applied. Existing in-flight
               GTD orders are not modified retroactively.

  SPF-CHG-008  circuit breaker changes (session_pause_
               drawdown, full_halt_drawdown) take effect
               immediately on the continuous bbo
               evaluation loop — not deferred to the
               next pipeline evaluation. The live
               Parameter Store is read for circuit
               breaker thresholds (not the frozen
               snapshot) per 0611002 HR-DD-012.

11. HARD RULES
============================================================

  HR-SPF-001  net 1:1.5 R:R is HARDCODED. It is a code
              literal. It is not in the Parameter Store.
              It cannot be changed by any mechanism.

  HR-SPF-002  All Risk-domain parameters are initialized
              to their starting values at every TothBot
              process start from the values in Section 6.
              CIATS writes updates after startup.

  HR-SPF-003  No CIATS parameter change below 200 closed
              trades. Starting values are immutable from
              CIATS below the floor.

  HR-SPF-004  Minimum 50-trade interval between any two
              parameter changes of any kind.

  HR-SPF-005  All Risk-domain parameter changes require
              Mann-Whitney U p < 0.01 (one-sided).

  HR-SPF-006  mae_mult changes must not cause net R:R
              to fall below 1:1.5 for any valid trade.

  HR-SPF-007  entry_timeout_sec applies to new orders
              only. In-flight orders are not modified.

  HR-SPF-008  Circuit breaker threshold changes take
              effect immediately on the live Parameter
              Store — not deferred to the snapshot.

  HR-SPF-009  Old 0511005 does not apply to TothBot V2.
              No mandatory human review gate exists for
              CIATS parameter changes.

  HR-SPF-010  Every parameter change is logged with full
              statistical support. No undocumented
              parameter changes are permitted.

12. FIVE CODING-READINESS QUESTIONS
============================================================

  (1) What does this document DO?
      Defines all Risk-domain Parameter Store starting
      values. Defines the one hardcoded exception
      (1:1.5 R:R — code literal, not Parameter Store).
      Specifies CIATS ownership rules and change
      constraints for all eight risk parameters.
      Specifies Parameter Store initialization sequence.
      Establishes the framework replacing retired 0511005.

  (2) What are its interfaces?
      Parameter Store (starting values written at startup),
      CIATS (change constraints govern all updates),
      Risk Engine (consumes all parameter values),
      Logger (all changes logged with statistical support).

  (3) What are its hard rules?
      HR-SPF-001 through HR-SPF-010 above. Critically:
      1:1.5 R:R is a code literal. 200-trade floor is
      absolute. 50-trade interval mandatory. Mann-Whitney
      p < 0.01 required. 0511005 retired.

  (4) What triggers it and what does it trigger?
      Triggered by: TothBot startup (initializes Parameter
      Store), CIATS parameter proposal approval (updates
      Parameter Store within constraints).
      Triggers: Gate 7, Gate 8, drawdown monitor consume
      updated values. Logger records every change.

  (5) What does it log?
      Every CIATS parameter change: parameter_name,
      old_value, new_value, trade_count_at_change,
      Mann-Whitney p-value, effect size, proposal_id.
      All changes logged at INFO level minimum. Changes
      that approach architectural constraint limits
      (e.g., mae_mult approaching R:R boundary) logged
      at WARNING.
