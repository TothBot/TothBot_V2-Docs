This document is the Sub-Domain Anchor for AA=08 Sub-Domain
1 — Trading_System_Modules. It anchors the instance

============================================================
3. SUB-DOMAIN 1 SCOPE
============================================================

Sub-Domain 1 (Trading_System_Modules) governs:

  - Long Module entry dispatch rules and order lifecycle
  - Short Module entry dispatch rules and order lifecycle
  - Selection Controller 6-gate quality filtering rules
  - Exit Controller 3-layer exit architecture and rules
  - Entry Limit Placement price computation rules
  - Position protection (TP + emergSL) placement rules
  - Cancel timeout fallback rules
  - MPP IOC retry rules
  - CIATS Trade Outcome Bus reporting rules

Sub-Domain 1 does NOT govern:

  - WS connection management (AA=05, 0511001)
  - SSS signal computation (AA=07, 0711001)
  - Regime classification (AA=07, 0711002)
  - Asset universe selection (AA=07, 0711003)
  - Risk sizing formulas (AA=06, 0611001)
  - Drawdown circuit breaker thresholds (AA=06, 0611002)
  - Kraken WS v2 wire protocol formats (AA=04, 0411001)
