TRADING_SYSTEM_MODULES_ANCHOR
============================================================

============================================================
1. PURPOSE
============================================================

This document is the Sub-Domain Anchor for AA=08 Sub-Domain
1 — Trading_System_Modules. It anchors the four instance
documents that specify TothBot V2 trading module rules to
the Trading System Domain Document (0800000).

This document defines the governance chain, the scope
boundary of Sub-Domain 1, and the mandatory reading and
dependency order for all instance documents in this
sub-domain.

============================================================
2. GOVERNING DOCUMENTS
============================================================

  0800000  Trading_System       (Domain Document — parent)
  0311001  Namespace_Specification
  0311002  Document_Creation_Workflow
  0500000  System_Architecture_Overview (primary source)

============================================================
3. SUB-DOMAIN 1 SCOPE
============================================================

Sub-Domain 1 (Trading_System_Modules) governs:

  - Long Module entry dispatch rules and order lifecycle
  - Selection Controller 6-gate quality filtering rules
  - Exit Controller 3-layer exit architecture and rules
  - Entry Limit Placement price computation rules
  - Position protection (TP + emergSL) placement rules
  - Cancel timeout fallback rules
  - MPP IOC retry rules
  - CIATS Trade Outcome Bus reporting rules

Sub-Domain 1 does NOT govern:

  - WS connection management (AA=05, 0511001)
  - SSS signal computation (AA=07, 0711001)
  - Regime classification (AA=07, 0711002)
  - Asset universe selection (AA=07, 0711003)
  - Risk sizing formulas (AA=06, 0611001)
  - Drawdown circuit breaker thresholds (AA=06, 0611002)
  - Kraken WS v2 wire protocol formats (AA=04, 0411001)

           TP, cancel emergSL, market sell sequence).
           cancel_timeout_window = 5.0s (FP/DP derived).
           mpp_retry_count = 3 (FP/DP derived). MPP IOC
           retry strategy. CIATS Trade Outcome Bus fields.
           Full Halt batch_cancel. Pair status adaptation.
           Hard rules. Interfaces. Logging events.

           Tier: Instance Document
           Depends on: 0810000, 0711001
           Content: entry_limit_price = candle close
           quantized DOWN to price_increment (AR-069).
           price_increment source from instrument channel.
           ROUND_DOWN quantization rationale. Hard rules.
           Interfaces. Logging.

============================================================
6. DEPENDENCY ORDER
============================================================

Commit order:
  1. 0800000 Trading_System (Domain Document)
  2. 0810000 This anchor
  3. 0811001, 0811002, 0811003, 0811004 (any order)

Within Sub-Domain 1, the four instance documents are
independent of each other. All four may be committed
in any order provided 0810000 and 0800000 are committed.

External dependencies:
  0811002 depends on 0711001 (SSS_Signal_Model_Specification)
    for SSS PASS signal definition (SC-GATE-1).
  0811004 depends on 0711001 for candle close price
    (the entry basis per AR-069).
  Both 0711001 and its parent chain (0710000, 0700000)
  must be on GitHub before 0811002 and 0811004 are
  committed.

System Architecture references:
  0811001 references 0511003 (Execution_Engine_Specification)
    and 0511005 (Position_Mirror_Specification).
  0811003 references 0511004 (Exit_Controller_Specification).
  These are reference-only relationships. The AA=05 docs
  must exist. The AA=08 docs are not copies — they define
  the trading-module rules at the AA=08 level.
