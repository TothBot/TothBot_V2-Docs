============================================================
2. SYSTEM IDENTITY
============================================================

TothBot V2 is an automated cryptocurrency spot trading
system running on Kraken using Python 3.12.3 on a
Hetzner VPS (Ubuntu 24.04.4 LTS).

TothBot V2 is a three-system organism:

  Zone 1 — Kraken:  Event source.
  Zone 2 — TothBot: Event processor. Executes trades.
  Zone 3 — CIATS:   Continuous improvement engine.
                    Owns all operating parameters.

Operator: Bill (sole operator).
Sole hardcoded constraint: Net 1:1.5 R:R — never changes.
Everything else: CIATS-owned starting values.

Primary mission: Maximize profit. Minimize loss.
Emphasis: Minimize loss. Loss prevention takes priority.

Modules (dependency order):
  1. Logger (no dependencies)
  2. WS Manager (depends on Logger)
  3. Position Mirror (depends on WS Manager)
  4. Regime Engine (depends on Logger)
  5. Risk Engine (depends on Logger, Position Mirror)
  6. Signal Pipeline (depends on WS Manager, Regime Engine)
  7. Selection Controller (depends on Signal Pipeline, Risk)
  8. Long Module (depends on Selection Controller)
  9. Execution Engine (depends on Long Module, WS Manager)
  10. Exit Controller (depends on Execution Engine, Risk)
  11. CIATS (depends on Logger — reads only)
  12. Startup Sequence (integrates all modules)

Completion criteria: All modules coded, unit tested,
integration tested. System runs end-to-end in test
mode against Kraken sandbox.

------------------------------------------------------------
PHASE 10 — PAPER TRADING                      [PENDING]
------------------------------------------------------------

Scope: Deploy to VPS. Run paper trading against live
       Kraken market data. No real capital at risk.
       Minimum duration and trade count required before
       go-live decision.

Paper trading governed by: 0211005 Paper_Trading_
Operations_Procedure.

Go-live criteria (minimum):
  - 200 closed trades (CIATS statistical inference floor)
  - No critical defects outstanding
  - CIATS Proposal Engine active and making parameter
    recommendations
  - Half-Kelly position sizing active (replaces fixed 5%)
  - All three Exit Controller layers validated
  - Emergency SL confirmed to never fire in normal ops
  - Drawdown circuit breakers validated
  - All alert channels confirmed operational
  - Bill review and approval of go-live decision

------------------------------------------------------------
PHASE 11 — LIVE TRADING (INITIAL)             [PENDING]
------------------------------------------------------------

Scope: Deploy with real capital. Conservative initial
       posture. CIATS owns all parameters from day one.

Initial capital posture:
  - 50% of portfolio tradeable (CIATS starting value)
  - 5% per trade (fixed until 200 closed trades)
  - Half-Kelly activates at 200 closed trades
  - Max 20 concurrent positions (CIATS starting value)

Standing constraint: Net 1:1.5 R:R — HARDCODED.
                     CIATS does not own this. Never changes.

Milestone: 600 closed trades — full per-regime analysis
           valid (100+ trades per regime bucket).
