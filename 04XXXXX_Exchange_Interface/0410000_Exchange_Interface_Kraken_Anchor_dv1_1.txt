Exchange Interface sub-domain (AA=04, B=1). It anchors

to the Exchange Interface Domain Document (0400000).

hierarchy chain for the Kraken exchange interface
sub-domain, allowing instance documents to have a valid

may be committed to GitHub without this anchor and 0400000

============================================================
4. SUB-DOMAIN SCOPE
============================================================

The Exchange Interface Kraken sub-domain governs the
complete technical interface specification between
TothBot V2 and the Kraken exchange. This sub-domain
covers Kraken exclusively. If TothBot V2 is ever extended
to a second exchange, that exchange receives its own
sub-domain anchor (B=2) under 0400000.

Each instance document elaborates one specific area of
the Kraken interface:

  0411002  Kraken_REST_API_Specification
           The complete Kraken REST API interface for
           all endpoints used by TothBot V2:
             GetWebSocketsToken  -- startup and reconnect
             GetOHLCData         -- daily regime (00:00 UTC)
             GetOpenOrders       -- reconciliation fallback
             GetAccountBalance   -- reconciliation fallback
             CancelAllOrders     -- emergency kill switch only
             Status API          -- proactive maintenance check
           All request formats, authentication requirements,
           response formats, error codes, and handling
           behaviors. CRITICAL: GetOHLCData response[-1]
           exclusion rule (HR-EI-004) must be specified
           explicitly in this document.

  0411003  Kraken_Fee_Rate_Limit_Specification
           The complete Kraken fee structure (maker/taker
           rates, fee tiers), rate limit rules (Intermediate
           Tier C-2 rate counter, decay rate, cost schedule
           per order type), API key configuration
           requirements, and CIATS monitoring hooks for
           fee actuals and rate counter actuals.
