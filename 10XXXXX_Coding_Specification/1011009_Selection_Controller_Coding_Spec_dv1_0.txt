SELECTION CONTROLLER CODING SPECIFICATION
============================================================

============================================================
1. PURPOSE
============================================================

This document is the complete, unambiguous coding contract
for the TothBot V2 Selection Controller — Gate 5 of the
8-gate trading pipeline. It applies 6 quality gates to
every SSS PASS signal and manages cooldown and consecutive
loss state across evaluations.

3. FIVE CODING-READINESS QUESTIONS
============================================================

(1) What does Selection Controller DO?
    Applies 6 quality gates in strict sequence to every
    SSS PASS signal. Returns PASS or FAIL with reject code.
    Manages two persistent in-memory state dicts: cooldown
    registry and consecutive loss counters. FAIL = skip
    (log reject code, continue pipeline for other pairs).
    Never halts pipeline.

(2) Interfaces?
    IN:  SSS PASS signal + candle data (close, open, volume)
         Pre-computation cache: atr_14[symbol], pair_cache
           (qty_min, cost_min)
         Position Mirror (SC-GATE-3: is symbol open?)
         Parameter Store snapshot: sc_body_threshold,
           sc_cooldown_seconds, sc_consecutive_limit
         Gate 8 preview: quantized qty estimate (SC-GATE-5)
    OUT: PASS → Long Module dispatch
         FAIL → Logger (reject code), pipeline skip

(3) Hard rules?
    Gates in strict sequence 1 → 6. First FAIL exits immediately.
    FAIL = SKIP. Never HALT. Pipeline continues for other pairs.
    sc_body_threshold applied to ATR(14) — not raw candle range.
    Cooldown uses time.monotonic() — never time.time().
    State dicts preserved across WS reconnect.
    sc_body_threshold, sc_cooldown_seconds, sc_consecutive_limit
      all read from Parameter Store snapshot (I-4).
    Consecutive loss count resets on win for that symbol.
    Consecutive loss count resets on CIATS instruction.

(4) What triggers it?
    SSS PASS signal from Signal Pipeline SSS Engine on
    every 5-minute candle evaluation.

(5) What does it log?
    GATE5_PASS: symbol, all 6 gates passed
    WEAK_CANDLE_BODY: symbol, body_size, threshold, atr_14
    POSITION_ALREADY_OPEN: symbol
    PAIR_IN_COOLDOWN: symbol, elapsed_seconds, remaining_seconds
    POSITION_TOO_SMALL: symbol, computed_qty, qty_min,
      computed_cost, cost_min
    CONSECUTIVE_LOSSES_EXCEEDED: symbol, count, limit

============================================================
4. IN-MEMORY STATE
============================================================

SC-STATE-001  Cooldown registry:
              cooldown_registry: dict[str, float] = {}
              # Key: symbol. Value: time.monotonic() of last exit.

SC-STATE-002  Consecutive loss counter:
              consecutive_loss_count: dict[str, int] = {}
              # Key: symbol. Default: 0 if not present.

SC-STATE-003  Both dicts preserved across WS reconnect.
              Not reset on reconnect or session restart.
              Only reset by win (cooldown+loss count reset)
              or CIATS instruction (loss count reset only).

SC-STATE-004  On position close — EXIT CONTROLLER calls back:

              def on_position_closed(symbol, was_win: bool):
                  """Called by Exit Controller on every close."""
                  # Update cooldown
                  cooldown_registry[symbol] = time.monotonic()
                  if was_win:
                      consecutive_loss_count[symbol] = 0
                  else:
                      consecutive_loss_count[symbol] = (
                          consecutive_loss_count.get(symbol, 0) + 1
                      )

============================================================
5. SIX QUALITY GATES
============================================================

SC-GATE-1  SSS Signal Pass
           All three SSS conditions confirmed true.
           (Already verified by Signal Pipeline SSS Engine
           before calling Selection Controller.)
           This gate is implicit — passes by arrival.

SC-GATE-2  Candle Body Strength
           Condition:
             candle_body = abs(candle_close - candle_open)
             threshold = atr_14[symbol] * sc_body_threshold
             # sc_body_threshold = 0.3 (CIATS-owned starting)
             PASS: candle_body > threshold
             FAIL: WEAK_CANDLE_BODY

           Implementation:
             candle_body = abs(Decimal(str(candle_close))
                               - Decimal(str(candle_open)))
             threshold = atr_14[symbol] * Decimal(str(
                 snapshot["sc_body_threshold"]))
             if candle_body <= threshold:
                 log("WEAK_CANDLE_BODY", symbol=symbol,
                     body=candle_body, threshold=threshold,
                     atr_14=atr_14[symbol])
                 return FAIL

SC-GATE-3  One Position Per Symbol
           Condition:
             PASS: symbol NOT in position_mirror
             FAIL: POSITION_ALREADY_OPEN

           Implementation:
             if symbol in position_mirror:
                 log("POSITION_ALREADY_OPEN", symbol=symbol)
                 return FAIL

SC-GATE-4  Post-Exit Cooldown
           Condition:
             PASS: symbol not in cooldown_registry
                   OR (time.monotonic() - cooldown_registry[symbol])
                   >= sc_cooldown_seconds
             FAIL: PAIR_IN_COOLDOWN
             # sc_cooldown_seconds = 300 (CIATS-owned starting = 1 candle)

           Implementation:
             if symbol in cooldown_registry:
                 elapsed = time.monotonic() - cooldown_registry[symbol]
                 remaining = snapshot["sc_cooldown_seconds"] - elapsed
                 if remaining > 0:
                     log("PAIR_IN_COOLDOWN", symbol=symbol,
                         elapsed_seconds=elapsed,
                         remaining_seconds=remaining)
                     return FAIL

SC-GATE-5  Minimum Position Size Pre-Validation
           Condition:
             PASS: quantized_qty >= qty_min
                   AND quantized_qty * entry_limit_price >= cost_min
             FAIL: POSITION_TOO_SMALL

           Implementation:
             # Preview Gate 8 sizing without committing
             entry_limit_price = Decimal(str(current_close))
             per_trade_usd = compute_per_trade_usd(snapshot)
             raw_qty = per_trade_usd / entry_limit_price
             quantized_qty = raw_qty.quantize(
                 pair_cache[symbol]["qty_increment"],
                 rounding=ROUND_DOWN
             )
             if quantized_qty < pair_cache[symbol]["qty_min"]:
                 log("POSITION_TOO_SMALL", symbol=symbol,
                     computed_qty=quantized_qty,
                     qty_min=pair_cache[symbol]["qty_min"])
                 return FAIL
             computed_cost = quantized_qty * entry_limit_price
             if computed_cost < pair_cache[symbol]["cost_min"]:
                 log("POSITION_TOO_SMALL", symbol=symbol,
                     computed_cost=computed_cost,
                     cost_min=pair_cache[symbol]["cost_min"])
                 return FAIL

SC-GATE-6  Consecutive Loss Limit
           Condition:
             count = consecutive_loss_count.get(symbol, 0)
             PASS: count < sc_consecutive_limit
             FAIL: CONSECUTIVE_LOSSES_EXCEEDED
             # sc_consecutive_limit = 3 (CIATS-owned starting)

           Implementation:
             count = consecutive_loss_count.get(symbol, 0)
             if count >= snapshot["sc_consecutive_limit"]:
                 log("CONSECUTIVE_LOSSES_EXCEEDED",
                     symbol=symbol,
                     count=count,
                     limit=snapshot["sc_consecutive_limit"])
                 return FAIL

SC-PASS    All 6 gates passed.
           log("GATE5_PASS", symbol=symbol)
           return PASS  # → Long Module dispatch

============================================================
6. HARD RULES
============================================================

HR-SC-001  Gates in strict sequence 1 → 6. No skipping.
HR-SC-002  FAIL = SKIP. Never HALT. Pipeline continues.
HR-SC-003  sc_body_threshold applied to ATR(14) multiple.
HR-SC-004  Cooldown uses time.monotonic(). Never time.time().
HR-SC-005  State dicts preserved across reconnect.
HR-SC-006  All CIATS params from Parameter Store snapshot.
HR-SC-007  Consecutive loss count resets on win. Never auto-clears on loss.
