GITHUB AUTOMATION CODING ANCHOR
============================================================

============================================================
1. PURPOSE
============================================================

This document is the Sub-Domain Anchor for all AA=10
Coding Specification documents governing TothBot V2
GitHub Document Control Automation (Pathway 1). It
anchors Sub-Domain 3 (DCN 103XXXX) to the AA=10 Domain
Document (1000000).

Pathway 1 automates enforcement of TothBot V2 document
control procedures via GitHub Actions. It is deferred
until after Pathway 2 reaches paper trading readiness
(PL-003).

============================================================
2. PARENT CHAIN
============================================================

  1000000  Coding_Specification        (Domain Document)
  1030000  This document               (Sub-Domain Anchor)

============================================================
3. PATHWAY 1 — SCOPE
============================================================

Execution environment:
  Platform:    GitHub Actions
  Trigger:     push and pull_request events on
               TothBot-V2-Docs repository
  Runtime:     GitHub-hosted runners
  Language:    Python 3.11+
  Repository:  github.com/TothBot/TothBot_V2-Docs

Pathway 1 runs ONLY in GitHub Actions on TothBot-V2-Docs.
It never runs on the VPS. It has no awareness of trading
system state. See TB00000 Section 3.4.3.

Pathway 1 does NOT:
  - Connect to Kraken or any exchange API
  - Read market data
  - Execute trades
  - Run on the VPS

============================================================
4. PATHWAY 1 FUNCTIONS
============================================================

  P1-F001  Validate 7-field document headers on every commit.
  P1-F002  Enforce DCN namespace compliance per 0311001.
  P1-F003  Enforce version increment rules per 0311003.
  P1-F004  Auto-correct correctable header violations.
  P1-F005  Enforce document lifecycle states (dv/rv/v/rt).
  P1-F006  Run approval workflow (Bill approval rv → v).
  P1-F007  Write document control audit logs.
  P1-F008  Reject non-compliant documents at commit time.
