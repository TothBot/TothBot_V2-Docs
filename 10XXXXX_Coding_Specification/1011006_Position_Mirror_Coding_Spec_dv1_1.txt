POSITION MIRROR CODING SPECIFICATION
============================================================

============================================================
1. PURPOSE
============================================================

This document is the complete, unambiguous coding contract
for the TothBot V2 Position Mirror. It is the single source
of truth for all open position state at runtime.

============================================================
3. FIVE CODING-READINESS QUESTIONS
============================================================

(1) What does Position Mirror DO?
    Maintains an in-memory O(1) symbol-keyed dict of all
    open positions. Written by WS Manager exclusively.
    Read by Signal Pipeline (Gates 5, 7), Exit Controller,
    Execution Engine, Risk Engine, and CIATS. Reconciled
    against Kraken snap_orders at startup and reconnect.
    Tracks all per-position state needed for exit, sizing,
    and CIATS tagging.

(2) Interfaces?
    Written by: WS Manager (sole writer — no other component)
    Read by:
      Signal Pipeline Gate 5 SC-GATE-3 (position exists?)
      Risk Engine Gate 7 (drawdown MTM computation)
      Exit Controller (tp_order_id, emgsl_order_id, qty)
      Execution Engine (record existence check pre-batch_add)
      CIATS EWMA Monitor (position count, regime tags)
    Reconciled against: Kraken executions snap_orders

(3) Hard rules?
    O(1) symbol-keyed dict — no list, queue, or ordered structure.
    Record created at dispatch BEFORE Kraken fill ACK (no async gap).
    entry_fill_price = actual avg_price from exec_type=filled. NEVER limit price.
    All Decimal values: Decimal(str()) immediately on receipt.
    WS Manager is SOLE writer. No other component writes directly.
    One position per symbol maximum (enforced by dict key).
    CIATS Trade Outcome Bus fires ONCE on full position close.
    portfolio_baseline_USD never reset on reconnect.

(4) What triggers updates?
    Entry dispatch → record created
    exec_type=filled (entry) → entry_fill_price, qty, timestamp updated
    batch_add ACK → tp_order_id, emgsl_order_id populated
    exec_type=trade (TP) → qty updated (partial fill)
    Exit confirmed → record deleted
    snap_orders reconciliation → records updated or gap-closed

(5) What does it log?
    POSITION_RECORD_CREATED: symbol, cl_ord_id, qty
    POSITION_FILL_CONFIRMED: symbol, avg_price, cum_qty
    POSITION_ORDERS_SET: symbol, tp_order_id, emgsl_order_id
    POSITION_QTY_UPDATED: symbol, new_qty (partial fill)
    POSITION_CLOSED: symbol, exit_reason
    GAP_CLOSED_POSITION: symbol (reconnect detection, HIGH)
    UNEXPECTED_OPEN_ORDER: order_id (WARN + operator alert)
    RECONCILIATION_COMPLETE: positions_confirmed, gap_closed

============================================================
4. DATA STRUCTURE
============================================================

from dataclasses import dataclass, field
from decimal import Decimal

@dataclass
class PositionRecord:
    symbol:               str
    cl_ord_id:            str      # TothBot-assigned entry cl_ord_id
    entry_limit_price:    Decimal  # placeholder until fill confirmed (HR-PM-002)
    entry_fill_price:     Decimal  # set on exec_type=filled (HR-PM-003)
    qty:                  Decimal  # current qty (decrements on partial TP)
    tp_order_id:          str      # Kraken-assigned TP order_id (set on batch_add ACK)
    tp_cl_ord_id:         str      # TothBot-assigned TP cl_ord_id
    emergsl_order_id:     str      # Kraken-assigned emergSL order_id
    emergsl_cl_ord_id:    str      # TothBot-assigned emergSL cl_ord_id
    entry_timestamp_utc:  str      # ISO 8601 from fill event
    entry_atr_14:         Decimal  # ATR(14) at entry for exit calcs
    asset_regime:         str      # regime_cache[symbol] at entry
    market_regime:        str      # regime_cache["BTC/USD"] at entry
    signal_params:        dict     # SSS signal values at entry
    hold_candle_count:    int = 0  # incremented on each 5m close

# The Position Mirror itself
position_mirror: dict[str, PositionRecord] = {}

5. WRITE OPERATIONS
============================================================

------------------------------------------------------------
5.1 Record Creation (at entry dispatch — before fill)
------------------------------------------------------------

PM-CREATE-001  Called by WS Manager immediately when
               Execution Engine dispatches add_order.
               Created BEFORE Kraken response (no async gap).
               WSManager method: pm_create() — called by EE
               via self._wm.pm_create().

               def pm_create(
                       symbol, cl_ord_id, entry_limit_price,
                       qty):
                   position_mirror[symbol] = PositionRecord(
                       symbol=symbol,
                       cl_ord_id=cl_ord_id,
                       entry_limit_price=entry_limit_price,
                       entry_fill_price=Decimal("0"),  # pending
                       qty=qty,
                       tp_order_id="",        # pending
                       tp_cl_ord_id="",       # pending
                       emergsl_order_id="",   # pending
                       emergsl_cl_ord_id="",  # pending
                       entry_timestamp_utc="", # pending
                       entry_atr_14=Decimal("0"),
                       asset_regime="",
                       market_regime="",
                       signal_params={},
                       hold_candle_count=0
                   )
                   log("POSITION_RECORD_CREATED",
                       symbol=symbol,
                       cl_ord_id=cl_ord_id,
                       qty=qty)

------------------------------------------------------------
5.2 Update on Entry Fill
------------------------------------------------------------

PM-FILL-001    Called when exec_type=filled received for
               entry cl_ord_id.
               WSManager method: pm_on_fill() — called by EE
               via self._wm.pm_on_fill().

               def pm_on_fill(symbol, fill_price,
                              qty, timestamp_utc):
                   if symbol not in position_mirror:
                       log("FILL_WITHOUT_RECORD",
                           level="CRITICAL", symbol=symbol)
                       return
                   rec = position_mirror[symbol]
                   rec.entry_fill_price   = Decimal(str(fill_price))
                   rec.qty                = Decimal(str(qty))
                   rec.entry_timestamp_utc = timestamp_utc
                   log("POSITION_FILL_CONFIRMED",
                       symbol=symbol,
                       fill_price=rec.entry_fill_price,
                       qty=rec.qty)

------------------------------------------------------------
5.3 Update on batch_add ACK (TP + emergSL order IDs)
------------------------------------------------------------

PM-ORDERS-001  Called when batch_add ACK confirms TP and
               emergSL order_ids from Kraken.
               WSManager method: pm_on_orders() — called by EE
               via self._wm.pm_on_orders().

               def pm_on_orders(symbol, tp_order_id,
                                emgsl_order_id):
                   if symbol not in position_mirror:
                       return
                   rec = position_mirror[symbol]
                   rec.tp_order_id      = tp_order_id
                   rec.emergsl_order_id = emgsl_order_id
                   log("POSITION_ORDERS_SET",
                       symbol=symbol,
                       tp_order_id=tp_order_id,
                       emgsl_order_id=emgsl_order_id)

------------------------------------------------------------
5.4 Update on TP Partial Fill
------------------------------------------------------------

PM-PARTIAL-001 Called when exec_type=trade for TP order_id
               with cum_qty < tp_qty.

               def on_tp_partial_fill(symbol, remaining_qty):
                   if symbol not in position_mirror:
                       return
                   rec = position_mirror[symbol]
                   rec.qty = Decimal(str(remaining_qty))
                   log("POSITION_QTY_UPDATED",
                       symbol=symbol,
                       new_qty=rec.qty)

------------------------------------------------------------
5.5 Update on ohlc(5m) Close (hold_candle_count)
------------------------------------------------------------

PM-CANDLE-001  WS Manager increments candle count on every
               5m OHLC close for pairs with open positions.

               def on_candle_close(symbol):
                   if symbol in position_mirror:
                       position_mirror[symbol].hold_candle_count += 1

------------------------------------------------------------
5.6 Record Deletion (position close)
------------------------------------------------------------

PM-CLOSE-001   Called after confirmed position close.
               NEVER delete before close is confirmed.
               WSManager method: close_position() for full
               exits (Exit Controller path).
               WSManager method: pm_clear() for entry
               cancel/expire no-fill (EE path).

               def close_position(symbol, exit_reason):
                   if symbol not in position_mirror:
                       log("CLOSE_WITHOUT_RECORD",
                           level="HIGH", symbol=symbol)
                       return
                   del position_mirror[symbol]
                   log("POSITION_CLOSED",
                       symbol=symbol,
                       exit_reason=exit_reason)

               def pm_clear(symbol):
                   # Entry cancel or expire with no fill
                   if symbol not in position_mirror:
                       return
                   del position_mirror[symbol]
                   log("POSITION_RECORD_CLEARED",
                       symbol=symbol,
                       reason="ENTRY_CANCELED_OR_EXPIRED_NO_FILL")

============================================================
6. RECONCILIATION
============================================================

PM-RECON-001  At startup (Step 6 of 1011014) and on every
              mid-session reconnect: compare Position Mirror
              against Kraken snap_orders.

PM-RECON-002  For each symbol in position_mirror but NOT in
              snap_orders open orders:
                Position was closed during gap.
                Log GAP_CLOSED_POSITION (HIGH).
                Fire CIATS Trade Outcome Bus with available data.
                Call close_position(symbol, "GAP_CLOSED").

PM-RECON-003  For each open order in snap_orders but NOT in
              position_mirror:
                Unexpected. Alert operator. Do NOT auto-manage.
                Log UNEXPECTED_OPEN_ORDER (WARN + alert).

PM-RECON-004  On reconnect: portfolio_baseline_USD NOT reset.
              drawdown_pct preserved. system_state preserved.
              Per HR-PM-006 (AR-056, AR-052).

PM-RECON-005  After reconciliation:
              Log RECONCILIATION_COMPLETE with:
                positions_confirmed count
                gap_closed_positions count

============================================================
7. READ ACCESS PATTERNS
============================================================

PM-READ-001   Gate 5 SC-GATE-3 (one position per symbol):
                is_open = symbol in position_mirror

PM-READ-002   Risk Engine drawdown MTM:
                open_value = sum(
                    bid_price[sym] * position_mirror[sym].qty
                    for sym in position_mirror
                )

PM-READ-003   Exit Controller (get order IDs):
                rec = position_mirror.get(symbol)
                if rec:
                    tp_id = rec.tp_order_id
                    sl_id = rec.emgsl_order_id
                    qty   = rec.qty

PM-READ-004   Execution Engine (pre-batch_add check):
                assert symbol in position_mirror, (
                    f"No record for {symbol} before batch_add")

============================================================
8. HARD RULES
============================================================

HR-PM-001  O(1) dict. Never list or ordered structure.
HR-PM-002  Record created at entry dispatch (before fill ACK).
HR-PM-003  entry_fill_price = actual avg_price from fill event.
HR-PM-004  All Decimal values: Decimal(str()) immediately.
HR-PM-005  CIATS Trade Outcome Bus fires ONCE on full close.
HR-PM-006  On reconnect: baseline and drawdown_pct preserved.
HR-PM-007  Unexpected snap_orders: alert + log. No auto-trade.
HR-PM-008  One position per symbol. Dict enforces this.
HR-PM-009  WS Manager is SOLE writer. No other component writes.
