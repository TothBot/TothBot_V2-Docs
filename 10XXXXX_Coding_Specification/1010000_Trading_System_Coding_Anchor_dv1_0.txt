3. PATHWAY 2 — TRADING SYSTEM SCOPE
============================================================

Pathway 2 governs the TothBot V2 automated cryptocurrency
spot trading system running on Kraken exchange.

Execution environment:
  Platform:    Hetzner VPS (87.99.141.44)
  OS:          Ubuntu 24.04.4 LTS
  Python:      3.12.3
  Exchange:    Kraken Spot (WebSocket v2 + REST)
  Clock:       Kraken OHLC 5-minute candle close (WS push)
  Repository:  github.com/TothBot/TothBot_V2-Code

Pathway 2 runs ONLY on the VPS. It never runs in GitHub
Actions. It has no awareness of document control state.
See TB00000 Section 3.4.3 — Pathway Separation Rules.

6. ENGINEERING CONSTRAINTS — ALL MODULES
============================================================

All Pathway 2 modules MUST comply with 1011001
Engineering_Best_Practices. Key constraints:

  EC-001  Python 3.12.3. No other version.
  EC-002  uvloop replaces default asyncio event loop.
  EC-003  orjson replaces stdlib json for all JSON ops.
  EC-004  TCP_NODELAY set on all WebSocket connections.
  EC-005  Async-first. No blocking calls on hot path.
  EC-006  Logger is the ONLY write path to disk.
          No module writes directly to disk.
  EC-007  CIATS reads ONLY from Logger output.
          CIATS writes ONLY to Parameter Store.
  EC-008  Parameter Store snapshot frozen at pipeline
          start. CIATS writes at inter-trade boundaries.
  EC-009  Net 1:1.5 R:R is HARDCODED. Not configurable.
          Not CIATS-owned. Never changes.
  EC-010  All prices and quantities rounded before
          order dispatch per AR-047 rounding rules.

============================================================
7. LOCKED ARCHITECTURAL REQUIREMENTS
============================================================

All 0500000 Architectural Requirements (AR-001 through
AR-012+) are binding on all Pathway 2 coding specs.
Key ARs:

  AR-001  No Dead Man Switch. No DMS/FIX cancel-on-disconnect.
  AR-002  Position Mirror: symbol-keyed dict, O(1) lookup.
  AR-003  Restart reconciliation: snap_orders:true PREFERRED.
  AR-004  Two API key pairs — DATA and TRADE.
          Nonce window 10,000ms.
  AR-005  WS v2 only. No WS v1.
  AR-006  Entry order: limit/post_only/GTD/cancel_newest/
          deadline:now+5s. WS v2 uses underscore format.
  AR-007  TP: resting limit via batch_add on fill.
          Actual fill price for R:R computation.
  AR-008  emergSL: stop-market via batch_add atomic with TP.
          ATR(14) x 3.0x. OTO. Not conditional order.
  AR-009  Short module deferred.
  AR-010  24/7/365. CIATS adds stand-down via PDCA.
  AR-011  Net 1:1.5 R:R SACRED. Hardcoded. Not CIATS.
  AR-012  Fee baseline: Maker 0.16% / Taker 0.26%.
