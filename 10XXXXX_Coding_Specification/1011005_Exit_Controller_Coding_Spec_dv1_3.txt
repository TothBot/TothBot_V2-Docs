EXIT CONTROLLER CODING SPECIFICATION
============================================================

============================================================
1. PURPOSE
============================================================

This document is the complete, unambiguous coding contract
for the TothBot V2 Exit Controller. It covers all three
active exit layers. Code is written from this document
and no other.

The Exit Controller owns all normal position exits. It
never opens positions. Layer 3 (emergSL) is a resting
order on Kraken's matching engine — Exit Controller
only interacts with it during normal exit sequences.

3. FIVE CODING-READINESS QUESTIONS
============================================================

(1) What does Exit Controller DO?
    Monitors all open positions. Fires Layer 1a signal-based
    exits (HTF reversal, regime downgrade, time expiry).
    Handles Layer 1b TP fills (full and partial). Coordinates
    Layer 2 MAE threshold exits via WS Manager. Handles TP
    partial fills by amending emergSL qty. Fires CIATS Trade
    Outcome Bus on every position close. Updates Position
    Mirror. Releases BoundedSemaphore slot.

(2) Interfaces?
    IN:  ohlc(60) events — 1H EMA cache (L1a HTF check)
         Regime Engine — regime_cache at 00:00 UTC (L1a regime)
         bbo ticker events — bid price (L2 MAE monitoring)
         executions channel — TP fill events (L1b)
         Position Mirror — all open positions
         Parameter Store — cancel_timeout, max_hold_candles
    OUT: cancel_order (TP + emergSL via WS Manager)
         amend_order (emergSL qty on partial TP fill)
         add_order market sell (L1a and L2 exits)
         CIATS Trade Outcome Bus (via Logger)
         Position Mirror update (clear on close)
         BoundedSemaphore release (Risk Engine)

(3) Hard rules?
    NEVER market sell with ambiguous cancel state.
    ALWAYS cancel TP before canceling emergSL.
    cancel_timeout_window = 5.0 seconds (CIATS starting value).
    mpp_retry_count = 3 (CIATS starting value).
    Layer 2 MAE breach takes priority over any pending L1a.
    TP partial fill → amend emergSL (NOT cancel+resubmit).
    CIATS Trade Outcome Bus fires ONCE per closed position.
    exit_reason mandatory on every closure.
    time.monotonic() for all timeout tracking (not time.time()).
    In cancel_only or maintenance status: HOLD, alert, no orders.

(4) What triggers it?
    ohlc(60) close events (HTF reversal check)
    00:00 UTC regime refresh (regime downgrade check)
    bbo ticker events for open position pairs (MAE monitoring)
    exec_type=filled or trade for TP/emergSL order IDs
    5m candle count per position (max_hold_candles check)

(5) What does it log?
    Every L1a decision with exit_reason and symbol.
    Every cancel attempt: sent, ACK received, timeout.
    CANCEL_TIMEOUT events (CRITICAL).
    TP_FILLED, TP_PARTIAL_FILL with qty and prices.
    EMERG_SL_AMENDED with old and new qty.
    LAYER2_EXIT_TRIGGERED with MAE pct and bid.
    CIATS Trade Outcome Bus record (TRADE_CLOSE — full fields).
    PAIR_CANCEL_ONLY_HOLD, PAIR_MAINTENANCE_HOLD (CRITICAL).

============================================================
4. PARAMETERS
============================================================

  cancel_timeout_window:  5.0 seconds  (CIATS-owned)
  mpp_retry_count:        3 attempts   (CIATS-owned)
  max_hold_candles:       24 candles   (CIATS-owned = 2 hours)
  mae_mult:               1.5x ATR(14) (CIATS-owned)

All read from Parameter Store snapshot (frozen at pipeline
start). EXCEPTION: circuit breaker thresholds read live.
time.monotonic() for all timeout tracking.

============================================================
5. LAYER 1a — SIGNAL-BASED EXITS
============================================================

Three L1a triggers. Each uses the same exit sequence.

------------------------------------------------------------
5.1 Standard L1a Exit Sequence
------------------------------------------------------------

EC-L1A-SEQ  For any L1a trigger on symbol:

  Step 1: Check pair status.
          If status == cancel_only or maintenance:
            Log PAIR_CANCEL_ONLY_HOLD or PAIR_MAINTENANCE_HOLD.
            Alert CRITICAL. Do NOT proceed. Resting orders protect.

  Step 2: cancel_order(tp_order_id) via WS Manager.
          Record req_id. Start cancel_timeout_window timer
          using time.monotonic().

  Step 3: Await TP cancel ACK (exec_type=canceled for tp_order_id).
          If ACK within timeout: proceed to Step 4.
          If timeout:
            Check executions state for tp_order_id.
            Confirmed canceled: proceed.
            State unknown: retry once.
            Second timeout: log CANCEL_TIMEOUT_HOLD (CRITICAL).
                           Alert operator. HOLD position.
                           NEVER issue market sell.

  Step 4: cancel_order(emergsl_order_id) via WS Manager.
          Same timeout pattern as Step 2-3.

  Step 5: After both confirmed canceled:
          Issue market sell at current bid (taker 0.26%).
          add_order: market/immediate-or-cancel for full qty.

  Step 6: Handle MPP rejection (if market sell rejected):
          Retry up to mpp_retry_count (3) times.
          If all retries fail: log MAE_HOLD_AMBIGUOUS (CRITICAL).
          Alert operator. Position remains open with no protection.

  Step 7: On sell fill confirmed:
          Fire CIATS Trade Outcome Bus (Section 8).
          Clear Position Mirror for symbol.
          Release BoundedSemaphore slot.

------------------------------------------------------------
5.2 Trigger 1: HTF Regime Reversal (EC-L1A-001)
------------------------------------------------------------

EC-L1A-001  TRIGGER: 1H EMA(20) crosses BELOW EMA(50)
            while a long position is open.

EC-L1A-002  CHECKING: Evaluated on EVERY ohlc(60) candle
            close event for all pairs with open positions.
            WS Manager updates 1H EMA cache on each ohlc(60).
            Exit Controller reads cache after each 60m event:

              async def on_ohlc_60_close(symbol, ema_20, ema_50):
                  if symbol not in position_mirror:
                      return
                  if ema_20 < ema_50:
                      await execute_l1a_exit(
                          symbol, "HTF_REGIME_REVERSAL")

EC-L1A-003  BASIS: Gate 4 entry requires EMA(20) > EMA(50).
            Symmetric reversal eliminates the documented edge.

------------------------------------------------------------
5.3 Trigger 2: Daily Regime Downgrade (EC-L1A-002)
------------------------------------------------------------

EC-L1A-006  TRIGGER: At 00:00 UTC regime refresh, pair
            reclassified to TRENDING_NEG or NON_DIR+ELEVATED
            while a long position is open.

EC-L1A-007  CHECKING: Immediately after Regime Engine updates
            regime_cache at 00:00 UTC:

              async def on_regime_update():
                  for sym in list(position_mirror.keys()):
                      state = regime_cache.get(sym)
                      if state is None:
                          continue
                      if state.directional == TRENDING_NEGATIVE:
                          await execute_l1a_exit(
                              sym, "DAILY_REGIME_DOWNGRADE")
                      elif (state.directional == NON_DIRECTIONAL
                            and state.vol_regime == ELEVATED_VOL):
                          await execute_l1a_exit(
                              sym, "DAILY_REGIME_DOWNGRADE")

EC-L1A-008  BASIS: Gate 3 blocks entries in these regimes.
            Holding an open position in a NO-ENTRY regime
            has no documented edge.

------------------------------------------------------------
5.4 Trigger 3: Time-Based Exit (EC-L1A-003)
------------------------------------------------------------

EC-L1A-010  TRIGGER: Position held >max_hold_candles 5-minute
            candles (24 = 2 hours) without TP fill.

EC-L1A-011  CHECKING: On every 5m candle close, for each
            open position increment its candle_count:

              async def on_candle_close(symbol):
                  if symbol not in position_mirror:
                      return
                  position_mirror[symbol]["candle_count"] += 1
                  if (position_mirror[symbol]["candle_count"]
                          >= max_hold_candles):
                      await execute_l1a_exit(
                          symbol, "TIME_EXPIRY")

EC-L1A-012  candle_count initialized to 0 at position open.
            Incremented on EVERY 5m candle close for that pair
            regardless of pipeline gate outcomes.

============================================================
6. LAYER 1b — TP FILL HANDLING
============================================================

------------------------------------------------------------
6.1 Full TP Fill
------------------------------------------------------------

EC-TP-001  TRIGGER: exec_type=filled for tp_order_id.
           This is a complete fill. Position fully closed.

           Response:
             (1) cancel_order(emergsl_order_id)
                 Cancel timeout pattern per EC-L1A-SEQ.
             (2) After cancel confirmed:
                 Fire CIATS Trade Outcome Bus:
                   exit_reason = "TP_FILL"
                   exit_price = tp fill avg_price
                 Clear Position Mirror for symbol.
                 Release BoundedSemaphore slot.
                 Log TP_FILLED with full P/L.

------------------------------------------------------------
6.2 Partial TP Fill
------------------------------------------------------------

EC-TP-002  TRIGGER: exec_type=trade for tp_order_id with
           cum_qty < tp_order_qty.

           Response:
             remaining_qty = tp_order_qty - cum_qty
             remaining_qty = remaining_qty.quantize(
                 pair_cache[sym]["qty_increment"],
                 rounding=ROUND_DOWN
             )

             Check minimums:
               if remaining_qty < pair_cache[sym]["qty_min"]:
                   → EC-TP-BELOW-MIN path
               if remaining_qty * bid < pair_cache[sym]["cost_min"]:
                   → EC-TP-BELOW-MIN path

             Normal path (remaining_qty >= minimums):
               amend_order(emergsl_order_id, remaining_qty)
               Update position_mirror[sym]["qty"] = remaining_qty
               Log TP_PARTIAL_FILL with filled and remaining.

EC-TP-003  BELOW-MIN path (remaining too small to protect):
             cancel_order(emergsl_order_id)
             After cancel confirmed: market sell remaining_qty.
             Clear Position Mirror.
             Fire CIATS Trade Outcome Bus (exit_reason="TP_FILL"):
               exit_price = weighted avg of TP fills + sell proceeds
             Log TP_PARTIAL_FILL_BELOW_MIN_EXIT.

EC-TP-004  WHY amend_order (not cancel+resubmit):
           amend_order rate cost: +2 units.
           cancel_order + add_order rate cost: +3 units.
           amend_order saves 1 unit AND preserves queue position.
           Queue position matters during volatile TP events.

EC-TP-005  Final fill after partial (exec_type=filled):
           Same as EC-TP-001 but:
             exit_price = cum_cost / total_cum_qty (weighted avg)
           This is the final unified CIATS record.

EC-TP-006  PRIORITY CONFLICT — TP partial + MAE breach simultaneous:
           Layer 2 (MAE breach) takes priority.
           Cancel remaining TP qty. Execute Layer 2 exit.
           Use cum_qty already filled as partial P/L.
           Send one unified CIATS Trade Outcome Bus record:
             exit_reason = "MAE_THRESHOLD_BREACH"

============================================================
7. LAYER 2 — MAE THRESHOLD EXIT
============================================================

EC-L2-001  TRIGGER: MAE >= ATR(14) * mae_mult (1.5x).
           MAE = entry_fill_price - bid_price (bid only, AR-048).
           Checked on EVERY bbo ticker event for the symbol.

EC-L2-002  SEQUENCE:
             (1) cancel_order(tp_order_id)
                 Cancel timeout pattern per EC-L1A-SEQ.
             (2) cancel_order(emergsl_order_id)
                 Cancel timeout pattern.
             (3) After both confirmed: market sell at bid.
                 exit_reason = "MAE_THRESHOLD_BREACH"
             (4) CIATS Trade Outcome Bus. Clear Mirror. Release semaphore.

EC-L2-003  Layer 2 takes priority over any in-progress L1a.
           If L1a sequence is underway and MAE breach fires:
           Complete the cancel sequence and execute market sell.
           Exit reason = MAE_THRESHOLD_BREACH.

EC-L2-004  Log LAYER2_EXIT_TRIGGERED with:
           symbol, MAE_pct_reached, bid_price, atr_14.

============================================================
8. LAYER 3 — EMERGENCY SL (NOT EC'S DOMAIN)
============================================================

EC-L3-001  Layer 3 (emergSL) is a resting stop-market order
           on Kraken's matching engine. It fires autonomously
           if TothBot fails. Exit Controller does NOT manage
           Layer 3 during normal operation.

           Exit Controller Layer 3 interactions:
             (a) Cancel emergSL after TP full fill (EC-TP-001).
             (b) Cancel emergSL before Layer 1a/2 market sell.
             (c) Amend emergSL qty on TP partial fill (EC-TP-002).

EC-L3-002  emergSL fires autonomously (EMERGENCY_SL_FIRED event):
           Log EMERGENCY_SL_FIRED (CRITICAL). Alert operator.
           Reconcile Position Mirror on next reconnect/startup.
           This is a system failure event — not normal operation.

============================================================
9. CIATS TRADE OUTCOME BUS
============================================================

EC-TOB-001  Fires ONCE per complete position close.
            Never on partial fills alone.
            Log event code: TRADE_CLOSE (level INFO).

EC-TOB-002  Mandatory fields — ALL must be populated:

  ts:                    ISO 8601 UTC with microseconds
  event:                 "TRADE_CLOSE"
  level:                 "INFO"
  component:             "EXIT_CTRL"
  symbol:                str
  entry_fill_price:      Decimal (avg_price at entry fill)
  exit_price:            Decimal (weighted avg if partials)
  entry_timestamp_utc:   ISO 8601 UTC
  exit_timestamp_utc:    ISO 8601 UTC
  hold_candle_count:     int (5m candles held)
  MAE_pct_reached:       Decimal (max adverse move as pct)
  fees_entry_usd:        Decimal (maker fee on entry)
  fees_exit_usd:         Decimal (taker fee on exit/TP)
  fees_total_usd:        Decimal
  exit_reason:           str — one of:
                           TP_FILL
                           MAE_THRESHOLD_BREACH
                           HTF_REGIME_REVERSAL
                           DAILY_REGIME_DOWNGRADE
                           TIME_EXPIRY
                           TP_PARTIAL_FILL_REMAINDER
  asset_regime:          str (pair regime at entry)
  vol_regime:            str (NORMAL_VOL | ELEVATED_VOL)
  market_regime:         str (BTC/USD regime at entry)
  signal_params:         dict {rsi_14, ema_9, ema_21,
                               volume_ratio, sss_pass}
  actual_RR:             Decimal (net_PL / risk_exposed)
  net_PL_USD:            Decimal
  net_gain_usd:          Decimal (0.0 if loss)
  net_loss_usd:          Decimal (0.0 if gain, positive value)

EC-TOB-003  Partial fill exit_price computation:
              exit_price = total_exit_proceeds / total_exit_qty
              total_exit_proceeds = sum of (fill_qty * fill_price)
                                    for all exit fills
              All arithmetic in Decimal.

============================================================
10. HARD RULES
============================================================

HR-EC-001  NEVER issue market sell with ambiguous cancel state.
HR-EC-002  ALWAYS cancel TP before canceling emergSL.
HR-EC-003  cancel_timeout_window: 5.0 seconds STARTING value;
           CIATS-owned. MUST be read at use-time via
           self._params.get("cancel_timeout_window",
           CANCEL_TIMEOUT_WINDOW). Direct constant usage
           is a defect (HR-EC-015).
HR-EC-004  mpp_retry_count: 3 STARTING value; CIATS-owned.
           MUST be read at use-time via self._params.get(
           "mpp_retry_count", MPP_RETRY_COUNT). Direct
           constant usage is a defect (HR-EC-015).
HR-EC-005  Layer 2 MAE breach takes priority over L1a.
HR-EC-006  TP partial fill: amend emergSL. NOT cancel+resubmit.
HR-EC-007  CIATS Trade Outcome Bus: fires ONCE per position.
HR-EC-008  exit_reason MUST be set on every closure.
HR-EC-009  Position Mirror cleared ONLY after confirmed close.
HR-EC-010  Parameter Store snapshot governs (except circuit breakers).
HR-EC-011  cancel_only/maintenance: HOLD, alert, no orders.
HR-EC-012  time.monotonic() for all timeout tracking. Never time.time().

HR-EC-013  PAPER-LIVE CLOSE-PATH PARITY (NEW dv1_3,
           cascaded from 0511004 dv1_3 HR-EC-013).
           _close_position() close sequence is byte-
           identical between paper and live modes
           downstream of (exit_price, fees_exit)
           determination. Same TRADE_CLOSE log payload,
           same Position Mirror clearing, same Selection
           Controller state updates, same semaphore
           release. Per §10A EC-PAPER and TB00000 v2_18
           §4.4 PA-005 byte-identical paper-live outside
           PA-004.

HR-EC-014  SELECTION CONTROLLER STATE UPDATE AUTHORITY
           (NEW dv1_3, cascaded from 0511004 dv1_3
           HR-EC-014). Exit Controller is the SOLE
           updater of Selection Controller state
           (wm.exit_cooldown_log,
           wm.consecutive_loss_count) in BOTH paper
           and live modes. The dv1_25
           ws_manager._fire_ciats_outcome path is
           RETIRED. _close_position() performs the SC
           state update on every close in BOTH modes
           using AR-073 win/loss classification:

             WIN_EXIT_REASONS = {"TP_FILL",
                                 "TP_PARTIAL_FILL_REMAINDER"}
               -> consecutive_loss_count[symbol] = 0
               -> exit_cooldown_log[symbol] cleared
                  (no re-entry penalty on win per
                  selection_ctrl.py SC-024)

             LOSS_EXIT_REASONS = {"MAE_THRESHOLD_BREACH",
                                  "TIME_EXPIRY",
                                  "HTF_REGIME_REVERSAL",
                                  "DAILY_REGIME_DOWNGRADE",
                                  "SIGNAL_DECAY",
                                  "MOMENTUM_LOSS",
                                  "EMERGENCY_SL"}
               -> consecutive_loss_count[symbol] += 1
               -> exit_cooldown_log[symbol] =
                  time.monotonic()

           Closes paper-mode SC state divergence.

HR-EC-015  CIATS-OWNED PARAMETERS — NO HARDCODED USAGE
           (NEW dv1_3, cascaded from 0511004 dv1_3
           HR-EC-015). All CIATS-owned starting values
           used by Exit Controller (mae_mult,
           cancel_timeout_window, mpp_retry_count,
           max_hold_candles, and any future addition)
           MUST be read at use-time from the CIATS
           Parameter Store / WS Manager config snapshot
           via self._params.get(key, DEFAULT_CONSTANT).

           Module-level constants (CANCEL_TIMEOUT_WINDOW,
           MPP_RETRY_COUNT, MAX_HOLD_CANDLES, MAE_MULT)
           serve ONLY as the second argument to
           self._params.get(); they MUST NOT be used
           directly in business logic.

           Example BEFORE (defect):
             threshold = atr_14 * MAE_MULT
             # MAE_MULT is a module constant.
             # CIATS proposals to change mae_mult cannot
             # take effect here.

           Example AFTER (correct):
             mae_mult = Decimal(str(
                 self._params.get("mae_mult", MAE_MULT)))
             threshold = atr_14 * mae_mult
             # CIATS Parameter Store snapshot supplies
             # the value; constant is the fallback.

           Direct constant usage in business logic is a
           defect that defeats CIATS PDCA for the
           affected parameter and creates cross-module
           parameter inconsistency (concrete failure
           mode: CIATS proposes mae_mult 1.5 -> 1.7;
           risk_engine sizes for wider stops;
           exit_controller still triggers L2 at 1.5x —
           closes positions BEFORE they reach the new
           threshold the rest of the system was sized
           for).

           Closes FINDING-TB00147-07 at the coding-spec
           layer. Code edit to exit_controller.py in
           TB00148 implementation session per dv1_3
           Revision History "CODE IMPACT" enumeration.

10A. PAPER MODE EXIT CODING CONTRACT (EC-PAPER) — NEW dv1_3
============================================================

Cascaded from 0511004 dv1_3 §6A EC-PAPER. This section
specifies the implementation contract for paper-mode
exit handling in exit_controller.py.

------------------------------------------------------------
10A.1 New Public Method
------------------------------------------------------------

EC-PAPER-CODE-001  on_paper_close ENTRY POINT.

           Add new public async method to
           ExitController class:

             async def on_paper_close(
                 self,
                 symbol: str,
                 exit_price: Decimal,
                 exit_reason: str,
                 fees_exit: Decimal,
                 wm: "WSManager",
             ) -> None:
                 """
                 Paper-mode exit entry point per
                 0511004 dv1_3 EC-PAPER-002.
                 Called by ws_manager._maybe_paper_fill
                 on TP fill detection or emergSL trigger.
                 ws_manager has already applied the
                 HR-WM-032 ledger update before invoking
                 this method.
                 """
                 if symbol not in wm.position_mirror:
                     # Position already cleared (race
                     # condition handling). Log and
                     # return.
                     self._logger.warning(log_record({
                         "event":     "PAPER_CLOSE_NO_POSITION",
                         "level":     "WARN",
                         "component": "EXIT_CTRL",
                         "symbol":    symbol,
                     }))
                     return

                 await self._close_position(
                     symbol=symbol,
                     exit_price=exit_price,
                     exit_reason=exit_reason,
                     fees_exit=fees_exit,
                     wm=wm,
                 )

           This entry point is the SOLE paper-mode
           exit interface from ws_manager. All paths
           in ws_manager.py paper code that previously
           called _fire_ciats_outcome MUST be replaced
           with calls to this method.

EC-PAPER-CODE-002  dispatch_market_sell RETURN CONTRACT.

           Cascaded from 1011002 dv1_26
           WM-PAPER-EXIT-004. ws_manager.dispatch_market_
           sell now returns (exit_price, fees_exit) as
           a tuple in BOTH modes:

             LIVE: returned values reflect the actual
                   exec_type=trade fills captured on
                   the executions channel (computed by
                   ws_manager._market_sell_with_retry).

             PAPER: returned values are synthesized
                    locally (current bid * qty for
                    proceeds; FEE_TAKER_PCT for fees).

           Exit Controller's existing
           _market_sell_with_retry helper (the EC-side
           retry orchestrator) MUST be updated to
           consume the new tuple return signature in
           both modes. This makes Layer 1a, Layer 2,
           and time-expiry exit paths byte-identical
           between paper and live without paper-
           specific branches in EC code.

EC-PAPER-CODE-003  _close_position SIGNATURE EXTENSION.

           The existing _close_position(symbol,
           exit_price, exit_reason, fees_exit, wm)
           method in exit_controller.py is sufficient
           — its current signature already accepts
           exit_price and fees_exit as parameters.
           No signature change required.

           Required changes to method body (TB00148
           implementation):

             (a) Read fees_entry_usd from
                 wm.position_mirror[symbol].fees_entry_usd
                 (PositionRecord field added by
                 1011002 dv1_26 WM-PAPER-LEDGER-002
                 entry-fill debit; live-mode entry
                 fill handler must also populate this
                 field if not already done).

             (b) Compute fees_total_usd = fees_entry_usd
                 + fees_exit (already in the method
                 body per dv1_2 — verify).

             (c) Add Selection Controller state update
                 per HR-EC-014 (move from
                 ws_manager._fire_ciats_outcome which
                 is being retired):

                   from tothbot.selection_ctrl import (
                       WIN_EXIT_REASONS,
                       LOSS_EXIT_REASONS,
                   )
                   if exit_reason in WIN_EXIT_REASONS:
                       wm.consecutive_loss_count[symbol] = 0
                       wm.exit_cooldown_log.pop(symbol,
                                                 None)
                   elif exit_reason in LOSS_EXIT_REASONS:
                       wm.consecutive_loss_count[symbol] = (
                           wm.consecutive_loss_count.get(
                               symbol, 0) + 1)
                       wm.exit_cooldown_log[symbol] = (
                           time.monotonic())

EC-PAPER-CODE-004  TRADE_CLOSE LOG SCHEMA (PARITY).

           The TRADE_CLOSE log record emitted by
           _close_position MUST contain identical
           fields in both paper and live modes:

             ts, event=TRADE_CLOSE, level=INFO,
             component=EXIT_CTRL, symbol,
             entry_fill_price, exit_price,
             entry_timestamp_utc, exit_timestamp_utc,
             hold_candle_count, MAE_pct_reached,
             fees_entry_usd, fees_exit_usd,
             fees_total_usd,
             exit_reason, asset_regime, vol_regime,
             market_regime, signal_params, actual_RR,
             net_PL_USD, net_gain_usd, net_loss_usd.

           NO mode flag in the log record. CIATS log-
           file polling is mode-agnostic. PA-005
           byte-identical CIATS data flow holds.
