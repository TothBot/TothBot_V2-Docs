============================================================
4. SUB-DOMAIN SCOPE
============================================================

The System Components sub-domain governs the complete
internal component specifications for all TothBot V2
modules that execute on the VPS. These documents define
what each component does, its interfaces, its hard rules,
what triggers it, and what it logs. Each document is
a coding-ready specification from which AA=10 coding
specifications and code can be directly derived.

No instance documents remain under this anchor. The last
instance document, 0511006 Logger_Specification, was retired
at TB00515 (the Logger is code-complete in the 0500000
diagrams -- DEC-072 bucket (c) = NONE; DEC-105). All System
Components architecture -- including the Logger as the sole
TothBot->CIATS data interface, the async bounded queue
(queue.Queue, maxsize=10,000, ar:AR-014 / ar:AR-063), the
QueueHandler + QueueListener never-block-the-hot-path
pattern, the full event-type set with minimum fields per
event, the CIATS Trade Outcome Bus fields, the EWMA Monitor
stream fields, and the alert levels -- is canonical in the
0500000 diagrams (DD-001 / DD-002).
